We made a form about applying to a job as one of Santa Claus' elves and creating an account for it. In order to assure a good UX and accessibility, we used peer-testing to confirm the easy-use of our page - some classmates tested our website and found the font sizes and colors to be clearly visible and on theme. We used color contrast testing websites, semantic html tags and meaningful images to enhance accessibility and communicate form structure to assistive technologies. For the UI part, we focused on making it visually appealing and used cohesive colors. We evaluated our website with the Lighthouse Chrome Extention and our proud to say we got a perfect score for accessibility and best practices and a 91 overall. We guided ourselves by the general principles framework of Jakob Nielsen's 10 Usability Heuristics. We learned from each unsatisfactory test we did, no matter if that was purely visual ones or external ones, and fixed any issued that came up each time. We provided intuitive feedback to users as they interact with the form and aimed to make it as self-explainatory as possible.
